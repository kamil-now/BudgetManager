REST API for managing personal budgets and expenses.

Authentication

This API uses JWT bearer tokens. To authenticate:

  1. Register an account via POST /auth/register
  2. Login via POST /auth/login to receive a token
  3. Click Authenticate at the top of the page, select Bearer and paste your token
  4. Your token will be remembered across page reloads

⚠️ This project is in early development. Expect breaking changes.
